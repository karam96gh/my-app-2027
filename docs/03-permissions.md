## تقليل البيانات والجلسة

الموظف يرى اسم زبون حجزه ومعرف الحجز والخدمة والوقت والحالة دون البريد والهاتف. قائمة التوافر لا تعيد حجوزات الآخرين أو سبب غياب الموظف. الإدارة ترى أسباب الغياب وسجل إلغاء المدير والحجوزات المتأثرة بالتغييرات.

تعديل الاسم لا يسمح بتعديل id أو role، ولا توجد كتابة حرة للحجز تتجاوز العمليات المخصصة. بيانات الموظف العامة هي الاسم والأهلية للخدمة دون تفاصيل الحساب الداخلية.

تبديل الحسابات الجاهزة ميزة للتجربة وليس مصادقة حقيقية. المدير موجود في seed، وإنشاء موظف محلي بواسطة المدير ينشئ ملف staff متسقاً. لا منح admin إضافي من الواجهة. إعادة ضبط التجربة أداة محلية صريحة تمسح الجلسة وتعيد seed، ولا تمثل حذف حساب حقيقي.

## الاختبارات المؤجلة

اختبارات API وJWT وRLS وGRANTS وSECURITY DEFINER وRPC غير منفذة حالياً. AC-SEC-* يختبر السلوك المحلي حيث ينطبق، وتوسم إثباتات أمان الخادم مؤجلة في 05. لا مفاتيح أو SDK أو إعداد Supabase.
