> الإصدار 1.1؛ اعتماد المستخدم 2026-10-22؛ المرجع requirements.md و06-decisions.md.

## البيئة وطبقات الاختبار

Fixtures: زبونان C-A/C-B، أربعة موظفين S-A..S-D، مدير AD-1، خدمة نشطة SV-A مرتبطة بأحمد، SV-B غير مرتبطة به، وخدمة معطلة SV-OFF. دوام 09:00–13:00 وغياب 11:00–12:00 بتاريخ مستقبلي وفق Asia/Damascus وClock قابل للحقن. بيانات منفصلة وقابلة لإعادة التهيئة، دون اعتماد ترتيب الاختبارات.

- Unit: قواعد الوقت والحالات وViewModels مع FakeRepository.
- Integration محلي: Repository وLocalFakeDataSource والتخزين واستعادة الجلسة.
- Widget/Manual: العرض والأدوار وLoading/Empty/Error وAndroid.
- Concurrency محلي: طلبان على نفس مثيل المصدر وفحص الحالة النهائية، دون إثبات معاملات خادم.
- لكل حالة: بيانات أولية، خطوات، نتيجة متوقعة، فحص الحالة النهائية، ونوع الاختبار ودليله.

## فحوص الأدوار المحلية

تنفذ باختبارات استدعاء Repository/DataSource مباشرة لا بإخفاء الأزرار فقط. إثبات API وJWT وRLS وGRANTS الحقيقي مؤجل لكل حالة أدناه.

| ID | المحاولة والنتيجة |
|---|---|
| AC-SEC-01 | حجز بلا جلسة: رفض. |
| AC-SEC-02 | قراءة حجوزات زبون آخر: منع. |
| AC-SEC-03 | ترقية الذات عبر تعديل الملف: رفض دون تغيير. |
| AC-SEC-04 | طلب الحجز لا يقبل customer_id؛ المالك من الجلسة. |
| AC-SEC-05 | طلب الحجز لا يقبل السعر؛ السعر من الخدمة. |
| AC-SEC-06 | لا تعديل عام لحالة الحجز خارج العمليات المخصصة. |
| AC-SEC-07 | الزبون لا يعدل خدمة أو سعرها أو تفعيلها. |
| AC-SEC-08 | الموظف لا يقرأ حجوزات موظف آخر. |
| AC-SEC-09 | الموظف لا يكمل حجز موظف آخر. |
| AC-SEC-10 | لا سبب إجازة أو بيانات اتصال خاصة في نتائج الزبون/الموظف. |
| AC-SEC-11 | غير المدير لا يستدعي عمليات الإدارة أو يعدل الدوام. |
| AC-SEC-12 | فحص المصدر والحزمة: لا أسرار أو SDK/إعداد Supabase أو اتصالات خارجية. |
| AC-SEC-13 | المستخدم المحدود لا يعدل تفعيل الموظف. |
| AC-SEC-14 | رفض حجز موظف لخدمة غير مؤهل لها. |

## بوابة التسليم والاختبارات المؤجلة

الإلزامي للتجربة: اختبارات المنطق وRepository والحفظ والواجهة والتداخل المحلي، وflutter analyze وflutter test وتجربة Android وAPK وREADME وتقرير أدلة النتائج.

المؤجل خارج النطاق: Supabase Auth وتأكيد البريد، اختبار JWT/API بمستخدمين حقيقيين، RLS/GRANTS/EXECUTE وSECURITY DEFINER، EXCLUDE ومعاملات PostgreSQL وتزامن أجهزة متعددة، وقت الخادم وسياسة حذف الهوية والاحتفاظ الحقيقية. تسجل «مؤجل — خارج نطاق التجربة»، ولا تسجل ناجحة بنتائج مصدر وهمي.

في نهاية كل خطوة تنفيذ تعرض النتائج والعوائق ويتوقف العمل حتى تأكيد المستخدم.
